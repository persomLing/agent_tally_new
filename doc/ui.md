# 个人记账小程序 UI 设计文档

## 1. 设计系统概览

| 项目 | 内容 |
|------|------|
| 产品名称 | 个人记账小程序 |
| 平台 | 微信小程序 |
| 设计风格 | 极简主义（Minimalism） |
| 设计关键词 | 大留白、圆角卡片、柔和阴影、清晰数字层级、浅色背景、清爽有质感 |

---

## 2. 设计风格

### 2.1 风格定位

采用 **极简主义（Minimalism）** 风格，核心原则：

- **内容即界面** — 数字和分类是视觉主体，装饰让位于信息
- **大留白** — 减少视觉噪音，让用户聚焦在金额和分类上
- **轻量化表达** — 卡片化布局，柔和阴影区分层级
- **色彩服务于功能** — 收入/支出使用颜色区分，不滥用色彩

### 2.2 风格参考

| 维度 | 选择 | 理由 |
|------|------|------|
| 整体调性 | 清爽、安静、有质感 | 财务工具需要理性感 |
| 卡片风格 | 圆角大卡片（16px） | 降低信息密度压迫感 |
| 阴影使用 | 柔和浅阴影（`box-shadow: 0 2px 8px rgba(0,0,0,0.06)`） | 层次清晰但不沉重 |
| 图标风格 | 线性图标（outline style） | 匹配极简调性，避免厚重 |
| 圆角体系 | 大圆角（12-16px）、中圆角（8px）、小圆角（4px） | 统一有节奏 |

## 4. 排版体系

### 4.1 字体

| 层级 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| H1 | 32px | Bold(700) | 1.3 | 金额数值展示 |
| H2 | 24px | SemiBold(600) | 1.3 | 页面标题、年月 |
| H3 | 18px | SemiBold(600) | 1.4 | 卡片标题、分类名称 |
| Body | 16px | Regular(400) | 1.5 | 账单金额、正文 |
| Body Small | 14px | Regular(400) | 1.5 | 辅助文字、备注 |
| Caption | 12px | Regular(400) | 1.4 | 日期、标签、占比 |

### 4.2 金额数字专用

| 层级 | 字号 | 字重 | 说明 |
|------|------|------|------|
| 记账页金额 | 40px | Bold(700) | 计算器输入态展示 |
| 详情页金额 | 20px | SemiBold(600) | 列表项中的金额 |
| 头部汇总 | 28px | Bold(700) | 明细页/统计页头部数字 |

### 4.3 排版规则

- 正文字号移动端最低 **16px**，防止 iOS 自动缩放
- 数字使用等宽字体或 tabular-nums，确保金额对齐时视觉稳定
- 行内金额与单位（￥）之间无空格
- 每行文字长度控制在 65-75 字符以内

## 5. 间距体系

采用 4px 为基础单位（WeChat Mini Program 常用 rpx 适配）：

| Token | px / rpx | 用途 |
|-------|----------|------|
| Space 1x | 4px | 极小间距 |
| Space 2x | 8px | 内边距、元素间距 |
| Space 3x | 12px | 列表项内部间距 |
| Space 4x | 16px | 卡片内边距、表单间距 |
| Space 5x | 20px | 区块间距 |
| Space 6x | 24px | 大区块间距 |
| Space 8x | 32px | 页面边距、留白 |

页面左右安全边距统一为 **20px**。

## 7. 圆角与阴影体系

### 7.1 圆角

| Token | 值 | 用途 |
|-------|-----|------|
| Radius SM | 4px | 小标签、图标容器 |
| Radius MD | 8px | 输入框、按钮 |
| Radius LG | 12px | 小卡片 |
| Radius XL | 16px | 大卡片、弹窗 |

| Token | 值 | 用途 |
|-------|-----|------|

## 10. 交互与动效规范

### 10.1 动效时长

| 场景 | 时长 | 说明 |
|------|------|------|
| 页面切换 | 250-300ms | 平滑过渡 |
| 按钮点击 | 100-150ms | 即刻反馈 |
| 卡片点击 | 150-200ms | 微缩放+阴影变化 |
| 弹窗出现 | 200-300ms | 淡入 + 上滑（底部弹窗） |
| 弹窗消失 | 150-200ms | 淡出 |
| 进度条动画 | 400-600ms | 从 0 到目标值 |
| 图表入场 | 500-800ms | 饼图扇形展开、柱状图从底上升 |

### 10.2 转场方式

| 场景 | 方式 |
|------|------|
| 底部 Tab 切换 | 无动画或淡入 |
| 明细 → 记账页 | 从底部滑入（slide-up） |
| 记账页返回明细 | 下滑出（slide-down） |
| 弹窗 | 从底部滑入（action sheet 风格） |
| 编辑模式进入 | 同新增，页面从底部滑入 |

### 10.3 触控反馈

| 场景 | 反馈 |
|------|------|
| 按钮点击 | `active` 态 0.95 缩放 + 背景加深 |
| 列表项点击 | 背景色短暂变深 `#F8FAFC` |
| 拖动悬浮按钮 | 松手后吸附动画 200ms ease-out |
| 分类选中 | 边框高亮 + 轻微放大 1.02x |
| 保存成功 | 轻提示 Toast "保存成功" |

### 10.4 reduced-motion

对于设置了 `prefers-reduced-motion` 的用户：

- 禁用所有超过 300ms 的动画
- 图表入场改为直接展示
- 页面切换改为无动画
- 弹窗改为直接出现

## 11. 无障碍规范

### 11.1 色彩对比度

| 场景 | 对比度要求 |
|------|-----------|
| 正文（16px+） | ≥ 4.5:1 |
| 大号文字（24px+） | ≥ 3:1 |
| 金额数字（大号） | ≥ 3:1 |
| 辅助文字（12px） | ≥ 4.5:1 |

当前颜色体系均已满足：

| 色值 | 对比度（白底） | 评级 |
|------|---------------|------|
| `#0F172A` (Text Primary) | 15.5:1 | AAA |
| `#475569` (Text Secondary) | 7.2:1 | AAA |
| `#94A3B8` (Text Tertiary) | 4.7:1 | AA |
| `#F43F5E` (Expense) | 5.8:1 | AA |
| `#10B981` (Income) | 4.7:1 | AA |
| `#4F6EF7` (Primary) | 5.3:1 | AA |

### 11.2 触控目标

- 所有可交互元素触控区域 ≥ **44x44px**
- 悬浮按钮、底部 Tab、列表项点击区域满足最小值
- 分类网格 icon 包裹在 ≥44px 容器内

### 11.3 其他无障碍

| 规则 | 说明 |
|------|------|
| 图标按钮 | aria-label 描述功能（如 "记账"、"返回"） |
| 金额语义 | 使用 `role="text"` 保证读屏正确朗读 |
| 图表替代 | 饼图/柱状图下方提供数据表格或文字描述 |
| 表单标签 | 备注等输入使用 label 关联 |
| 焦点管理 | 弹窗打开时焦点锁定，关闭时返回触发元素 |

## 12. 响应式与兼容性

### 12.1 屏幕适配

| 维度 | 规范 |
|------|------|
| 设计基准 | iPhone 12/13 宽度 390px |
| 适配方式 | 微信小程序 rpx 单位（750rpx 基准） |
| 最小宽度 | iPhone SE 320px |
| 最大宽度 | 自适应，不超 428px（iPhone Pro Max） |
| 安全区 | 全面屏底部 safe-area-inset-bottom |

### 12.2 关键断点

| 设备 | 逻辑宽度 | 处理方式 |
|------|---------|----------|
| iPhone SE | 320px | 4列分类改为 3列，边距 16px |
| iPhone 12/13 | 390px | 标准布局 |
| iPhone Pro Max | 428px | 标准布局，留白自然放大 |

### 12.3 滚动与固定

- 悬浮按钮使用 `position: fixed` 或小程序 `movable-view`
- 明细页顶部卡片 `position: sticky; top: 0`
- 统计页支持整体滚动，月份选择可 `sticky`
- 记账页底部计算器键盘固定，内容区自适应滚动
