# 账单管理模块任务清单

参考：`doc/proposal.md`（第 8.8、12、14.2、16.2~16.4、17.2~17.3 节），`doc/high-level-design.md`（第 4、5、6、7、10、11、13 节）

## 最小可执行任务（Vibe Coding）

- [ ] 创建记账页骨架：`/pages/bill-edit/index`，支持新增模式与编辑模式。
- [ ] 按 `doc/ui.md` 8.5 实现记账页 UI：类型切换、金额展示区、分类网格、日期选择、备注区、计算器键盘、删除区。
- [ ] 实现记账表单状态：`type`、`amount`、`categoryCode`、`billDate`、`remark`。
- [ ] 实现金额输入与校验：金额必填、`> 0`、两位小数、上限校验、重复提交防抖。
- [ ] 实现分类与日期必填校验，并映射为统一错误提示。
- [ ] 实现 `createBill` 云函数：写入 `bills` 集合并返回新账单 ID。
- [ ] 实现 `updateBill` 云函数：仅允许修改当前用户账单并更新时间。
- [ ] 实现 `deleteBill` 云函数：仅允许删除当前用户账单。
- [ ] 实现前端二次确认：删除账单、未保存退出。
- [ ] 实现记账页加载态与保存态：保存按钮 loading、禁用重复提交。
- [ ] 实现账单保存后联动刷新：通知明细、统计、个人中心刷新。
- [ ] 补充 `bills` 索引：`openid+billMonth+billDate`、`openid+type+billMonth`、`openid+billDate`。
- [ ] 自测：新增、编辑、删除、重复点击保存、未保存退出 5 条路径可闭环。
- [ ] 自测：记账页 UI 断言（类型切换高亮、分类选中态、校验错误视觉、编辑模式删除按钮）。
