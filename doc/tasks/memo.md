# 备注记忆库模块任务清单

参考：`doc/proposal.md`（第 11、12.5、12.7、12.14 节），`doc/high-level-design.md`（第 4、6、7、9、10、13 节）

## 最小可执行任务（Vibe Coding）

- [ ] 创建记忆库弹窗骨架：支持收入/支出切换与分类分组展示。
- [ ] 按 `doc/ui.md` 8.6 实现记忆库弹窗 UI：底部弹窗、分组折叠、备注项操作、新增入口、关闭按钮。
- [ ] 实现 `listMemos` 云函数：按 `type + categoryCode` 查询并按最近使用时间排序。
- [ ] 实现 `createMemo` 云函数：手动新增备注并避免同分类重复内容。
- [ ] 实现 `updateMemo` 云函数：编辑备注内容并更新时间。
- [ ] 实现 `deleteMemo` 云函数：删除指定备注（仅当前用户）。
- [ ] 实现自动沉淀逻辑：账单保存成功后，备注非空则写入/更新记忆库。
- [ ] 实现每分类最多 10 条规则：超限删除最早记录，保留最近 10 条。
- [ ] 在记账页实现备注联动：选中分类后拉取历史备注并支持一键填入。
- [ ] 实现记忆库空状态与错误提示。
- [ ] 自测：手动增删改、自动沉淀、去重、10 条上限淘汰策略。
- [ ] 自测：记忆库 UI 断言（分组展开收起、空状态、新增/编辑/删除按钮可见性）。
