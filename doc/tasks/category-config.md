# 分类配置模块任务清单

参考：`doc/proposal.md`（第 13 节），`doc/high-level-design.md`（第 4、8、9、16 节）

## 最小可执行任务（Vibe Coding）

- [ ] 新建分类常量文件：`src/constants/categories.ts`。
- [ ] 定义支出分类 10 项与收入分类 7 项，使用稳定 `categoryCode`。
- [ ] 定义分类元数据结构：`code`、`name`、`type`、`icon`、`color`、`sort`。
- [ ] 提供查询方法：按类型获取分类列表、按 `code` 反查分类信息。
- [ ] 在记账页接入分类常量，禁用自定义增删改入口。
- [ ] 在明细、统计、记忆库展示中统一使用分类配置映射名称与图标。
- [ ] 在云函数侧补分类合法性校验（写账单/备注时校验 `categoryCode`）。
- [ ] 自测：收入/支出分类隔离、“其他”分类独立、非法分类被拒绝。
