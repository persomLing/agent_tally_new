# 统计分析模块任务清单

参考：`doc/proposal.md`（第 9、15.3~15.10 节），`doc/high-level-design.md`（第 4、5、6、9、11 节）

## 最小可执行任务（Vibe Coding）

- [ ] 创建统计页骨架：`/pages/statistics/index`，包含月份选择、汇总区、分类统计区、近七日区、拓展统计区。
- [ ] 按 `doc/ui.md` 8.3 实现统计页 UI：汇总卡片、饼图区、排行榜区、近七日图表区、拓展统计卡片。
- [ ] 实现统计月份选择状态，默认当前月。
- [ ] 实现 `getStatistics` 云函数：返回月收入、月支出、月结余。
- [ ] 在 `getStatistics` 中实现支出分类占比与分类排行榜聚合。
- [ ] 在 `getStatistics` 中实现拓展统计：最多消费分类、最大单笔支出、记账笔数、记账天数。
- [ ] 在 `getStatistics` 中实现近七日收支（固定近 7 天，不受月份切换影响）。
- [ ] 实现统计页空状态：无支出数据、近七日无收支数据。
- [ ] 接入统计页图表加载占位与加载态切换。
- [ ] 接入账单变更刷新：新增/编辑/删除后重新拉取统计数据。
- [ ] 自测：月份切换、全零数据、仅收入、仅支出、跨月数据场景。
- [ ] 自测：统计页 UI 断言（空状态文案、排行榜排序渲染、图表容器状态切换）。
