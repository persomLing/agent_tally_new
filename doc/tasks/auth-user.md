# 授权与用户模块任务清单

参考：`doc/proposal.md`（第 7、14.1、16.1、17.1 节），`doc/high-level-design.md`（第 4、5、6、7、10 节）

## 最小可执行任务（Vibe Coding）

- [ ] 创建授权页骨架：`/pages/auth/index`，包含授权说明区与授权按钮入口。
- [ ] 按 `doc/ui.md` 8.1 实现授权页视觉：居中布局、品牌主按钮、拒绝提示样式、留白规则。
- [ ] 实现应用启动鉴权流程：启动时调用 `login` 云函数获取 `openid` 与授权状态。
- [ ] 实现 `login` 云函数：基于微信上下文获取 `openid`，查询或创建 `users` 记录。
- [ ] 实现授权提交流程：前端获取微信头像昵称后调用 `saveUserProfile`。
- [ ] 实现 `saveUserProfile` 云函数：更新 `nickName`、`avatarUrl`、`authorized`、`firstAuthorizedAt`。
- [ ] 实现授权拦截：未授权用户仅可停留授权页，不允许进入主业务页。
- [ ] 实现拒绝授权与授权失败提示文案（按需求文档文案）。
- [ ] 接入授权页加载态与按钮禁用态（防重复点击授权）。
- [ ] 在 `userStore` 落地用户状态：`openid`、昵称、头像、授权状态。
- [ ] 补充 `users` 集合索引：`openid` 唯一索引。
- [ ] 自测：首次进入、已授权复进、拒绝授权、授权失败 4 条路径可闭环。
- [ ] 自测：授权页 UI 断言（按钮高度、颜色语义、提示文案状态切换）。
