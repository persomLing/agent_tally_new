# 公共基础模块任务清单

参考：`doc/proposal.md`（第 12.8~12.11、15、17、20 节），`doc/high-level-design.md`（第 4、5.2、6.2、11、12、13、14 节）

## 最小可执行任务（Vibe Coding）

- [ ] 新建云函数调用封装：`src/services/cloud.ts`，统一请求与错误处理。
- [ ] 统一返回结构处理：解析 `CloudResult<T>`，封装成功/失败分支。
- [ ] 新建设计 Token：颜色、字号、间距、圆角、阴影（严格对齐 `doc/ui.md` 第 3~7 节）。
- [ ] 新建金额工具：`src/utils/money.ts`，实现元/分转换、金额格式化、精度处理。
- [ ] 新建日期工具：`src/utils/date.ts`，实现 `billMonth` 计算、近七日日期生成、月底天数计算。
- [ ] 新建校验工具：`src/utils/validator.ts`，覆盖金额、分类、日期、备注规则。
- [ ] 新建通用组件：`ConfirmDialog`、`EmptyState`、`MonthPicker`、`FloatingBillButton`。
- [ ] 按 `doc/ui.md` 落实组件规范：悬浮按钮尺寸/阴影/吸附、确认弹窗规格、空状态规格、加载态规格。
- [ ] 落地全局可访问性与适配基线：触控目标 >=44x44、文本对比度、safe-area 适配、320~428 宽度适配。
- [ ] 落地交互动效基线：点击反馈、弹窗出入场、页面切换时长（按 `doc/ui.md` 第 10 节）。
- [ ] 实现全局刷新机制：`billStore` 或事件总线，统一处理“账单已变更”通知。
- [ ] 统一错误码与文案映射：授权失败、参数错误、无权限、服务异常。
- [ ] 统一 loading/禁用态策略：防重复提交、防重复删除。
- [ ] 自测：公共工具单测或最小调用验证，覆盖金额精度与日期边界。
- [ ] 自测：通用组件样式与交互符合 `doc/ui.md`，并完成快照测试或 DOM 断言测试。
