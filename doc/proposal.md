## 2. 产品背景

本产品是一款面向个人用户的轻量级记账小程序，帮助用户快速记录每日收入与支出，并通过明细、统计分析、预算进度和备注记忆库等功能，帮助用户了解自己的消费结构和资金状态。

产品重点不是复杂财务管理，而是让用户可以低成本、快速、持续地完成记账行为。

---

## 3. 产品目标

1. 帮助用户快速记录收入和支出。
2. 帮助用户查看每日账单明细。
3. 帮助用户通过图表了解支出分类占比和近七日收支变化。
4. 帮助用户查看本月收入、支出、预算剩余和记账坚持情况。
5. 通过记忆库降低重复填写备注的操作成本。
6. 保持整体体验简洁、清爽、有设计感。

---

## 4. 用户角色

| 用户角色 | 说明 |
|---|---|
| 个人用户 | 使用微信授权进入小程序，记录自己的日常收入和支出，查看统计和预算情况 |

本产品 V1.0 仅支持个人使用，不支持多人共同记账，不支持家庭账本，不支持多账本。

## 6. 整体页面结构

小程序主要包含 3 个底部导航页面和 1 个记账页面。

### 6.1 底部导航

| 页面 | 说明 |
|---|---|
| 明细 | 展示每日收入和支出记录 |
| 统计 | 展示支出分类饼图和近七日收支柱状图 |
| 我的 | 展示用户信息、坚持记账天数、预算进度和记忆库 |

### 6.2 非底部导航页面

| 页面 | 说明 |
|---|---|
| 记账页 | 通过悬浮按钮进入，用于新增、编辑账单 |
| 授权页 | 首次进入时展示，用户必须微信授权后才可使用 |

## 7. 首次进入与微信授权

### 7.1 授权规则

1. 用户第一次进入小程序时，必须进行微信授权。
2. 授权内容用于获取微信头像和昵称。
3. 用户授权成功后，进入明细页面。
4. 用户拒绝授权时，不允许进入小程序。
5. 用户拒绝授权后，停留在授权页面，并提示用户授权后才能使用。

### 7.2 授权页模块

| 模块 | 内容 |
|---|---|
| 产品名称 | 展示小程序名称 |
| 产品说明 | 简要说明小程序用于个人记账 |
| 授权说明 | 告知用户需要获取微信头像和昵称 |
| 授权按钮 | 微信授权进入 |
| 拒绝提示 | 拒绝授权后提示无法进入 |

### 7.3 拒绝授权提示文案

> 需要授权微信头像和昵称后才能使用记账功能。

---

## 8. 明细页面需求

### 8.1 页面定位

明细页面用于展示每日收入和支出情况，是用户进入小程序后的默认首页。

页面采用下滑列表形式，头部固定展示当前年月和当月收入、支出汇总。

---

### 8.2 页面结构

| 区域 | 模块 | 说明 |
|---|---|---|
| 顶部固定区 | 年月选择 | 点击后选择年份和月份 |
| 顶部固定区 | 本月收入 | 展示当前月份收入总额 |
| 顶部固定区 | 本月支出 | 展示当前月份支出总额 |
| 内容区 | 日期分组 | 按日期分组展示账单 |
| 内容区 | 账单列表 | 展示每条收入或支出记录 |
| 悬浮区 | 记账按钮 | 可拖动，吸附在屏幕四周 |

---

### 8.3 年月选择

1. 默认展示当前年月。
2. 点击年月区域后，弹出年月选择器。
3. 用户选择年月后，页面刷新为对应年月账单。
4. 年月选择影响明细列表、本月收入、本月支出。

---

### 8.4 头部汇总

头部只展示以下内容：

| 字段 | 说明 |
|---|---|
| 当前年月 | 例如：2026年5月 |
| 本月收入 | 当前选择月份的收入总和 |
| 本月支出 | 当前选择月份的支出总和 |

明细页头部不展示结余、预算剩余、日均支出。

---

### 8.5 日期分组

账单按日期分组展示。

建议日期标题格式：

> 5月19日 星期二

同一天有多条账单时，全部展示在该日期分组下。

---

### 8.6 账单列表项

每条账单展示以下内容：

| 字段 | 是否展示 | 说明 |
|---|---|---|
| 分类图标 | 是 | 使用系统默认图标 |
| 分类名称 | 是 | 例如：餐饮、交通、工资 |
| 备注 | 是 | 用户填写的备注；为空时可不展示 |
| 金额 | 是 | 使用 + / - 区分收入支出 |
| 收入/支出文字标识 | 否 | 不额外展示，由金额符号区分 |
| 具体时间 | 否 | 本产品记账只精确到日期 |

金额展示规则：

| 类型 | 展示格式 |
|---|---|
| 支出 | -￥20.00 |
| 收入 | +￥500.00 |

---

### 8.7 空状态

当当前月份没有账单时，展示空状态。

建议文案：

> 暂无记账记录，点击下方按钮记一笔。

---

### 8.8 账单操作

1. 点击账单列表项，进入记账页编辑模式。
2. 编辑完成后返回明细页面。
3. 删除账单时需要二次确认。
4. 删除成功后返回明细页面。
5. 删除或修改后，明细页、统计页、个人中心相关数据需立即更新。

---

## 9. 统计分析页面需求

### 9.1 页面定位

统计分析页用于帮助用户了解本月支出结构、收支变化趋势和关键消费数据。

---

### 9.2 页面结构

| 区域 | 模块 | 说明 |
|---|---|---|
| 顶部区 | 月份选择 | 选择统计月份 |
| 顶部区 | 汇总卡片 | 展示本月收入、本月支出、本月结余 |
| 图表区 | 支出分类饼图 | 展示各支出分类占比 |
| 图表区 | 支出分类排行榜 | 展示各支出分类金额和占比 |
| 图表区 | 近七日柱状图 | 展示近七日收入和支出双柱对比 |
| 拓展区 | 本月消费最多分类 | 展示支出最高分类 |
| 拓展区 | 本月最大单笔支出 | 展示本月最大一笔支出 |
| 拓展区 | 本月记账笔数 | 展示本月账单数量 |
| 拓展区 | 本月记账天数 | 展示本月有账单的自然日数量 |
| 悬浮区 | 记账按钮 | 可拖动，吸附在屏幕四周 |

---

### 9.3 月份选择

1. 默认展示当前月份。
2. 点击月份后弹出月份选择器。
3. 月份选择影响以下模块：
   - 本月收入
   - 本月支出
   - 本月结余
   - 支出分类饼图
   - 支出分类排行榜
   - 本月消费最多分类
   - 本月最大单笔支出
   - 本月记账笔数
   - 本月记账天数
4. 近七日柱状图不受月份选择影响，始终展示今天往前七天。

---

### 9.4 顶部汇总卡片

| 字段 | 计算规则 |
|---|---|
| 本月收入 | 当前月份所有收入金额之和 |
| 本月支出 | 当前月份所有支出金额之和 |
| 本月结余 | 本月收入 - 本月支出 |

---

### 9.5 支出分类饼图

1. 饼图只统计支出分类。
2. 不统计收入分类。
3. 每个扇区代表一个支出分类。
4. 扇区占比 = 该分类支出金额 / 本月总支出。
5. 无支出数据时，展示空状态。

空状态建议文案：

> 本月暂无支出数据。

---

### 9.6 支出分类排行榜

饼图下方展示支出分类排行榜。

| 字段 | 说明 |
|---|---|
| 排名 | 按金额从高到低排序 |
| 分类图标 | 使用默认图标 |
| 分类名称 | 支出分类名称 |
| 分类金额 | 当前月份该分类支出总额 |
| 占比 | 该分类支出金额 / 本月总支出 |

排序规则：

> 支出金额越高，排名越靠前。

---

### 9.7 近七日柱状图

近七日柱状图展示今天往前 7 天的收入和支出双柱对比。

| 数据 | 说明 |
|---|---|
| 支出柱 | 当日支出总额 |
| 收入柱 | 当日收入总额 |
| 日期 | 展示近七日日期 |

规则：

1. 如果某天没有收入，收入柱显示为 0。
2. 如果某天没有支出，支出柱显示为 0。
3. 如果近七日完全没有收入，则视觉重点展示支出。
4. 该图表不受月份选择影响。

---

### 9.8 拓展统计模块

| 模块 | 说明 |
|---|---|
| 本月消费最多分类 | 当前月份支出最高的分类 |
| 本月最大单笔支出 | 当前月份金额最高的一笔支出 |
| 本月记账笔数 | 当前月份账单总数量 |
| 本月记账天数 | 当前月份有账单记录的自然日数量 |

---

## 10. 个人中心页面需求

### 10.1 页面定位

个人中心用于展示用户信息、坚持记账情况、本月预算进度和记忆库。

---

### 10.2 页面结构

| 区域 | 模块 | 说明 |
|---|---|---|
| 用户信息区 | 头像 | 来自微信授权 |
| 用户信息区 | 昵称 | 来自微信授权 |
| 用户信息区 | 坚持记账天数 | 累计有账单记录的自然日数量 |
| 预算区 | 本月预算进度条 | 本月支出 / 本月收入 |
| 预算区 | 距离月底天数 | 当前日期到月底剩余天数 |
| 预算区 | 预算剩余金额 | 本月收入 - 本月支出 |
| 功能区 | 记忆库 | 弹窗形式查看和编辑备注 |
| 功能区 | 隐私说明 | 展示隐私相关说明 |
| 功能区 | 清空全部账单数据 | 需要二次确认 |

---

### 10.3 用户信息

| 字段 | 说明 |
|---|---|
| 头像 | 微信授权获取 |
| 昵称 | 微信授权获取 |
| 坚持记账天数 | 累计有账单记录的自然日数量 |

坚持记账天数计算规则：

> 同一天无论记几笔账，都只算 1 天。

示例：

用户在 5 月 1 日记了 3 笔，5 月 3 日记了 1 笔，则坚持记账天数为 2 天。

---

### 10.4 本月预算进度

预算进度计算规则：

> 本月预算进度 = 本月支出 / 本月收入

预算剩余金额计算规则：

> 预算剩余金额 = 本月收入 - 本月支出

展示规则：

| 场景 | 展示方式 |
|---|---|
| 本月收入大于 0，支出未超过收入 | 展示进度条和预算剩余金额 |
| 本月收入为 0 | 显示“暂无收入，无法计算预算”，但展示本月支出 |
| 支出超过收入 | 显示“已超支 ￥xx” |

超支金额计算：

> 已超支金额 = 本月支出 - 本月收入

---

### 10.5 距离月底天数

距离月底天数按当前自然日期计算，不包含当天。

示例：

如果今天是 5 月 19 日，5 月共有 31 天，则展示：

> 距离月底还有 12 天

---

### 10.6 清空全部账单数据

个人中心提供清空全部账单数据入口。

规则：

1. 点击后弹出二次确认。
2. 用户确认后，清空全部账单数据。
3. 清空后，明细页、统计页、个人中心数据恢复为空状态。
4. 该操作不可撤销。

确认文案建议：

> 清空后所有账单数据将无法恢复，确定继续吗？

---

## 11. 记忆库需求

### 11.1 功能定位

记忆库用于记录每个分类下常用的备注内容，方便用户在记账时快速选择，减少重复输入。

---

### 11.2 入口形式

记忆库入口位于个人中心。

点击后以弹窗形式展示，不进入独立页面。

---

### 11.3 展示结构

记忆库弹窗包含：

| 模块 | 说明 |
|---|---|
| 类型切换 | 支出 / 收入 |
| 分类分组 | 按分类展示备注 |
| 备注列表 | 每个分类最多展示 10 条备注 |
| 编辑入口 | 支持编辑备注 |
| 删除入口 | 支持删除备注 |
| 添加入口 | 支持手动新增备注 |

---

### 11.4 备注来源

备注来源有两种：

1. 用户手动添加。
2. 用户记账时填写备注并保存成功后，自动保存到对应分类的记忆库。

---

### 11.5 数量限制

每个分类最多保存 10 条备注。

超过 10 条时：

> 自动删除最早的一条，保留最近 10 条。

---

### 11.6 保存规则

| 场景 | 规则 |
|---|---|
| 备注为空 | 不保存进记忆库 |
| 备注已存在 | 不重复保存 |
| 备注不为空且不存在 | 保存到对应分类 |
| 超过 10 条 | 删除最早一条 |

---

### 11.7 记账页联动

1. 用户在记账页选择分类后，展示该分类下的历史备注。
2. 点击历史备注后，自动填入备注输入框。
3. 收入分类和支出分类的备注互相独立。

---

## 12. 记账页面需求

### 12.1 页面定位

记账页用于新增账单和编辑账单。

通过三个主页面的悬浮记账按钮进入。

---

### 12.2 入口规则

| 入口 | 说明 |
|---|---|
| 明细页悬浮按钮 | 点击进入新增记账页 |
| 统计页悬浮按钮 | 点击进入新增记账页 |
| 我的页悬浮按钮 | 点击进入新增记账页 |
| 明细账单项 | 点击进入编辑记账页 |

---

### 12.3 悬浮记账按钮

1. 悬浮按钮显示在三个主页面。
2. 按钮可拖动。
3. 拖动后只能吸附在屏幕四周。
4. 按钮不应遮挡底部导航核心区域。
5. 点击按钮进入新增记账页。

---

### 12.4 页面模式

| 模式 | 说明 |
|---|---|
| 新增模式 | 创建一条新账单 |
| 编辑模式 | 编辑已有账单，详情页与编辑页合并 |

编辑模式中，页面默认填充该账单已有内容。

---

### 12.5 页面字段

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 类型 | 是 | 支出 / 收入 |
| 金额 | 是 | 通过计算器输入 |
| 分类 | 是 | 从默认分类中选择 |
| 日期 | 是 | 默认当天，可选择过去或未来日期 |
| 备注 | 否 | 可手动输入，也可从记忆库选择 |

---

### 12.6 默认状态

| 字段 | 默认值 |
|---|---|
| 类型 | 支出 |
| 日期 | 当天 |
| 金额 | 空 |
| 分类 | 未选择 |
| 备注 | 空 |

---

### 12.7 收入 / 支出切换

1. 页面顶部提供收入和支出切换。
2. 默认选中支出。
3. 切换类型后，分类列表同步切换。
4. 收入和支出的分类、备注记忆互相独立。

---

### 12.8 金额计算器

金额输入使用计算器形式。

支持按键：

| 按键 | 说明 |
|---|---|
| 0-9 | 输入数字 |
| 小数点 | 输入小数 |
| + | 加法 |
| - | 减法 |
| 删除 | 删除上一位 |
| 清空 | 清空当前输入 |
| 完成 | 保存账单 |

---

### 12.9 计算器规则

1. 金额必须大于 0。
2. 金额最多保留两位小数。
3. 不允许输入第三位小数。
4. 计算器展示计算过程，例如：`12 + 8 - 3`。
5. 点击完成后，只保存最终计算结果。
6. 单笔金额上限建议为：`￥9999999.99`。

---

### 12.10 日期规则

1. 日期默认当天。
2. 日期只精确到日，不精确到具体时间。
3. 支持补记过去日期。
4. 支持选择未来日期。
5. 账单统计按账单日期归属，不按创建日期归属。

示例：

用户在 5 月 19 日创建一条 6 月 1 日的账单，则该账单归属 6 月 1 日，并计入 6 月统计。

---

### 12.11 保存校验

点击完成时，按以下规则校验：

| 场景 | 提示文案 |
|---|---|
| 未输入金额 | 请输入金额 |
| 金额为 0 | 金额必须大于 0 |
| 未选择分类 | 请选择分类 |
| 金额超过上限 | 金额超出限制 |

## 15. 数据统计规则

### 15.1 月收入

> 月收入 = 当前月份所有收入账单金额之和

---

### 15.2 月支出

> 月支出 = 当前月份所有支出账单金额之和

---

### 15.3 月结余

> 月结余 = 月收入 - 月支出

---

### 15.4 预算进度

> 预算进度 = 本月支出 / 本月收入

当本月收入为 0 时，不计算预算进度，展示：

> 暂无收入，无法计算预算

---

### 15.5 预算剩余金额

> 预算剩余金额 = 本月收入 - 本月支出

当结果小于 0 时，展示为：

> 已超支 ￥xx

---

### 15.6 坚持记账天数

> 坚持记账天数 = 有账单记录的自然日数量

同一天多笔账单只计算为 1 天。

---

### 15.7 本月记账笔数

> 本月记账笔数 = 当前月份全部收入账单和支出账单数量之和

---

### 15.8 本月记账天数

> 本月记账天数 = 当前月份有账单记录的自然日数量

---

### 15.9 分类占比

> 分类占比 = 该分类支出金额 / 本月总支出

只统计支出分类。

---

### 15.10 近七日收支

> 近七日收支 = 从今天起向前推 7 天内，每日收入和支出金额之和

该统计不受统计页月份选择影响。

---

## 16. 交互流程

### 16.1 首次使用流程

1. 用户打开小程序。
2. 系统检测是否已授权。
3. 未授权则进入授权页。
4. 用户点击微信授权进入。
5. 授权成功后进入明细页。
6. 用户拒绝授权则停留在授权页，无法进入小程序。

---

### 16.2 新增记账流程

1. 用户点击任意主页面的悬浮记账按钮。
2. 进入记账页新增模式。
3. 默认类型为支出。
4. 用户输入金额。
5. 用户选择分类。
6. 用户选择日期，默认当天。
7. 用户填写备注，可选。
8. 用户点击完成。
9. 系统校验金额和分类。
10. 校验通过后保存账单。
11. 自动更新明细、统计和个人中心数据。
12. 返回明细页面。

---

### 16.3 编辑账单流程

1. 用户在明细页点击某条账单。
2. 进入记账页编辑模式。
3. 页面回显原账单内容。
4. 用户修改金额、分类、日期或备注。
5. 用户点击完成。
6. 系统保存修改。
7. 返回明细页面。
8. 相关数据立即更新。

---

### 16.4 删除账单流程

1. 用户在编辑模式下点击删除。
2. 系统弹出二次确认。
3. 用户确认删除。
4. 系统删除该账单。
5. 返回明细页面。
6. 相关数据立即更新。

---

### 16.5 查看统计流程

1. 用户点击底部导航“统计”。
2. 页面默认展示当前月份统计。
3. 用户可点击月份切换统计月份。
4. 页面刷新汇总卡片、饼图、排行榜和拓展数据。
5. 近七日柱状图始终展示最近七日收支。

---

### 16.6 编辑记忆库流程

1. 用户进入个人中心。
2. 点击记忆库入口。
3. 弹出记忆库弹窗。
4. 用户切换收入或支出。
5. 用户查看不同分类下的备注。
6. 用户可新增、编辑或删除备注。
7. 用户关闭弹窗后回到个人中心。

---

## 19. UI / UX 设计方向

### 19.1 整体风格

整体采用简洁清爽、有设计感的视觉风格。

关键词：

1. 大留白。
2. 圆角卡片。
3. 柔和阴影。
4. 清晰数字层级。
5. 浅色背景。
6. 收入和支出颜色区分。
7. 悬浮按钮突出但不打扰。

---

### 19.2 页面设计重点

| 页面 | 设计重点 |
|---|---|
| 明细页 | 一眼看清每天花了什么、收入了什么 |
| 统计页 | 一眼看清钱主要花在哪、最近收支趋势如何 |
| 个人中心 | 强化坚持记账的正反馈 |
| 记账页 | 少步骤、快输入、低干扰 |
| 记忆库 | 降低重复输入备注的成本 |

---

### 19.3 交互设计原则

1. 记账入口始终可见。
2. 记账路径尽量短。
3. 金额、分类、日期是保存前核心校验项。
4. 删除、清空、未保存退出都必须二次确认。
5. 统计图表优先表达结果，不增加复杂操作。
6. 分类固定，降低用户配置成本。
7. 历史备注自动沉淀，提高连续使用体验。

---

## 20. 非功能需求

### 20.1 易用性

1. 用户应能快速完成一笔记账。
2. 关键操作按钮需要明显。
3. 页面信息层级清晰。
4. 空状态需要有引导文案。

---

### 20.2 性能体验

1. 页面切换应流畅。
2. 明细列表下滑时应保持顺滑。
3. 图表加载不应明显卡顿。
4. 保存账单后应及时反馈。

---

### 20.3 数据安全

1. 清空全部账单数据前必须二次确认。
2. 用户授权信息仅用于个人中心展示。
3. 隐私说明入口需要在个人中心展示。

---

### 20.4 兼容性

1. 页面应适配常见手机屏幕尺寸。
2. 悬浮记账按钮拖动后不得遮挡底部导航。
3. 弹窗内容过长时需要支持滚动。

---

## 21. 版本边界总结

V1.0 版本重点是完成个人记账闭环：

> 授权进入 → 记一笔 → 查看明细 → 查看统计 → 查看预算 → 使用记忆库提高记账效率

本版本保持轻量，不做复杂账户体系和高级财务功能。
